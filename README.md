# 自动制版 V0.9（Adobe Illustrator 面板扩展）

把「标签制版动作自动化插件」搬进 Illustrator 内嵌面板：预检、参数、执行、报告都在面板完成，  
不再走「文件 > 脚本 > 其他脚本」。

- 面板名称：**自动制版**　外侧文件夹：**zidongzhiban**
- Bundle ID：`com.workbuddy.ai.zidongzhiban`
- 当前版本：**V0.9**（版本历史见 `更新日志.txt`）

## 核心功能

- **一键全流程**：处理前栅格对照 → 分色拆层 → 清理转曲 → 色板/四色黑处理 → 刀线叠印 → 出血蒙版 → 归类候选 → 导出前校验，一次跑完
- **多文件连续作业**：切换/打开文档自动重跑预检（V0.8），不用重开面板或 AI
- **面板即报告**：结果区就是自检报告（文档名 · 时间 · 版本），不落盘任何报告文件
- **分级暂停导出**：日志落笔即定级（通过 / 已自动修正 / 待人工确认 / 异常暂停），有异常就停，不带着问题往下走
- **文档内标注**：可定位的待人工确认对象（转曲失败、归类不明、搬层失败等）自动圈注到「待确认-自动标记」图层，红圈+编号，不参与导出（V0.9）
- **自动修正**：解锁、转曲、四色黑转单黑补叠印、刀线叠印等能修的直接修，每条修正可核验
- **人工辅助核对**：自动找同目录标版 EPS / JPG 小样并摆放到画板右侧，专色清单自动列出
- **复杂版面不瞎动**：分色搬层、保线、归类等无法保证正确的步骤，只出候选结果并标人工确认

## 安装

1. 把整个 `zidongzhiban` 文件夹解压到任意位置（**路径不要含中文或空格**）。
2. 双击 `windows一键安装.bat`（复制到 `%APPDATA%\Adobe\CEP\extensions\zidongzhiban`，并打开 CEP 调试模式）。
3. **重启 Illustrator** → `窗口 > 扩展 > zidongzhiban`。

卸载：双击 `windows一键卸载.bat`。

## 使用

1. 打开 AI 文件（建议先另存一份副本——V0.7 起不强制，但流程会直接修改文档）。
2. 面板自动预检：刀线路径条数、是否已另存、是否已有对照层。
3. 选**产品类型**（标签 3mm / 礼盒 5mm 出血）；多条刀线时在下拉里按实际规格选主刀线。
4. 点「开始制版」→ 确认 → 看**结论**（可导出 / 导出已暂停）→ 按需处理文档里的红圈标注 → 人工核对后删除标记图层。

## 边界与已知限制

- 流程**会修改文档且不可撤销**：检测到已有对照层会拒绝重复运行，请用原始副本。
- 保线（trapping）本轮完全不参与。
- 分色搬层只对简单版面自动执行，复杂版面只标记人工确认。
- 专色与 JPG 小样核对只做「列清单 + 摆小样」，不做图片文字识别（需外部 OCR）。
- 「规格线尺寸数据库」「JPG/AI 自动套对」「夜间批量」不在本阶段范围。
